# 나락퀴즈쇼 🎤

학생들이 직접 질문과 선택지를 입력하고, 어떤 선택지를 골라도 **"나락"**으로 향하는 교실용 퀴즈쇼 웹앱.

- **편집 화면**: 질문 + 선택지(2~4개) + 출제자 이름 입력, 질문 목록 관리, 예시 질문 제공
- **쇼 화면**: 네온 인트로 → AI 진행자 음성(TTS) + 타자 효과 질문 → 선택지 순차 공개 → 카운트다운 타이머 → "나락 확정" 판정 연출 → 엔딩 통계
- 조작: 숫자키 `1~4` 선택 · `Space`/`Enter` 진행 · `Esc` 종료 · 터치(전자칠판) 지원
- 저장: 브라우저 localStorage에 자동 저장 · 서버 불필요(파일 하나로 동작)
